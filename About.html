About

A developer who got curious about how things break.

Deepak, based in New Delhi. Started in frontend and full-stack development, shipped real product features, and then went looking for the part of the job no one taught him — proving the thing actually works before a user finds out it doesn't. That's QA now: manual and automated, Playwright-first.

The journey

Dev first. QA next. Both, now.

2023 — 2025

I started as a builder.

Self-taught MERN, then Angular/PrimeNG on the job at Chipin Corp — a Gaming Zone site, a Job Application Tracker, Purchase Order components.

Late 2025

Then I started breaking things on purpose.

Manual test cases in Excel first — Login, Registration — before trusting myself with automation. Then Playwright: Page Object Model, 20+ E2E tests, GitHub Actions CI.

Now

I do both — that's the edge.

A QA engineer who reads the codebase, not just the UI. Currently sharpening SQL and API testing with Postman.
